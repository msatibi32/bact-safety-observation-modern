Diagram 2 — Alur Pelapor (Form Publik)

Alur lengkap dari pelapor membuka aplikasi hingga laporan tersimpan dengan status Open.

flowchart TD
    START([Pelapor buka app / scan QR]) --> FORM[Halaman Form Pelaporan]

    FORM --> S1["Info Pelapor\nNama · Departemen · Perusahaan"]
    S1 --> S2["Lokasi & Waktu\nTanggal · Lokasi teks · GPS opsional"]
    S2 --> S3["Detail Observasi\nKategori · Deskripsi · Tingkat risiko"]
    S3 --> S4["Bukti & Tindakan\nFoto · Tindakan langsung · Rekomendasi"]

    S4 --> VALID{Form valid?}
    VALID -->|Tidak| FORM
    VALID -->|Ya| UPLOAD[Upload foto ke Storage]
    UPLOAD --> INSERT["Insert observations\nstatus = Open"]
    INSERT --> SUCCESS[Laporan terkirim]
    SUCCESS --> AGAIN{Lapor lagi?}
    AGAIN -->|Ya| FORM
    AGAIN -->|Tidak| END([Selesai])

    S2 -.-> GPS{Izin GPS?}
    GPS -->|Ya| GPS_OK[Simpan koordinat]
    GPS -->|Tidak| GPS_SKIP[Lanjut tanpa GPS]

    style START fill:#dcfce7,stroke:#22c55e
    style END fill:#dcfce7,stroke:#22c55e
    style VALID fill:#fef3c7,stroke:#f59e0b
    style AGAIN fill:#fef3c7,stroke:#f59e0b
    style INSERT fill:#f3e8ff,stroke:#a855f7

Diagram 3 — Alur Admin / HSE Officer

Alur login admin, penanganan laporan, assign PIC, update status, dan akses ringkasan analitik.

flowchart TD
    START([Admin buka /admin/login]) --> LOGIN[Input email + password]
    LOGIN --> AUTH{Auth berhasil?}
    AUTH -->|Tidak| ERR[Error: email/password salah]
    ERR --> LOGIN
    AUTH -->|Ya| DASH[Dashboard /admin]

    DASH --> STATS["Statistik: Total · Open · High risk"]
    DASH --> FILTER[Filter status]
    FILTER --> TABLE[Tabel daftar laporan]
    TABLE --> SELECT[Pilih laporan]
    SELECT --> DETAIL[Panel detail + foto bukti]

    DETAIL --> ACTION["Follow-up:\nAssign PIC · Ubah status · Catatan penutupan"]
    ACTION --> SAVE[Simpan ke Supabase]
    SAVE --> DASH

    DASH --> SUMMARY[Ringkasan /admin/ringkasan]
    SUMMARY --> CHARTS["Analitik:\nRisiko · Departemen · Perusahaan · Lokasi · Rekomendasi"]

    DASH --> LOGOUT[Logout]

    style START fill:#dcfce7,stroke:#22c55e
    style AUTH fill:#fef3c7,stroke:#f59e0b
    style SAVE fill:#f3e8ff,stroke:#a855f7

Diagram 4 — State Machine Status Laporan

Perpindahan status laporan dari Open hingga Closed beserta kondisi transisinya.

stateDiagram-v2
    [*] --> Open : Pelapor submit

    Open --> InProgress : Admin assign PIC\n& mulai tindak lanjut
    Open --> Closed : Tutup langsung\n+ catatan penutupan

    InProgress --> Closed : Tindakan selesai\n+ catatan penutupan

    Closed --> [*] : closed_date tercatat

    note right of Open
        Laporan baru masuk
        Belum ada PIC
    end note

    note right of InProgress
        PIC sudah di-assign
        Follow-up berjalan
    end note

    note right of Closed
        Wajib catatan penutupan
        Tanggal close tersimpan
    end note

Diagram 6 — Workflow Target (Standar Migas / Roadmap)

Diagram ini menunjukkan alur target mengacu standar ISO 45001 & praktik industri migas. Belum seluruhnya diimplementasi — gunakan sebagai rencana pengembangan. 
flowchart TD
    SUBMIT([Pelapor Submit]) --> TRIAGE{HSE Triage\nReview severity}

    TRIAGE -->|Low / Medium| ASSIGN[Assign PIC]
    TRIAGE -->|High / HiPo| ESCALATE[Eskalasi Supervisor\n+ Investigasi wajib]

    ESCALATE --> INVEST[Investigasi\n5 Whys / Root Cause]
    INVEST --> CAPA[Buat CAPA\nCorrective Action]

    ASSIGN --> PROGRESS[In Progress]
    CAPA --> PROGRESS

    PROGRESS --> VERIFY{Verifikasi HSE\nTindakan efektif?}
    VERIFY -->|Belum| PROGRESS
    VERIFY -->|Ya| CLOSED[Closed]

    CLOSED --> REPORT[Dashboard & Export\nAudit ISO 45001]
